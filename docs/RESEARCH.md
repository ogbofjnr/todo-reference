npm registry (`npm view <pkg> version`, peer ranges, publish dates) on the day, not
recalled from memory. Decisions and their trade-offs live in [the ADRs](adr/); this
page is the evidence they rest on.

## Notable findings

- **TypeScript 7 vs typescript-eslint.** TS 7.0 (Go port) is the npm `latest` tag. It has no stable programmatic API until 7.1, and
  `typescript-eslint@8.72.1` declares `typescript: >=4.8.4 <6.1.0`. Type-aware linting is a core
  requirement here, so we use TS 6.0.3. A typecheck-only `tsgo` alongside it would be a second
  compiler to keep consistent, for a project whose typecheck already takes about 2 seconds.
- **ESLint 10 vs jsx-a11y.** `eslint-plugin-jsx-a11y@6.10.2` (last release October 2024) peers on
  `eslint ^3 … ^9`. Its rules work on ESLint 10: we checked by adding violations and seeing them reported.
  The peer is allowed explicitly in `pnpm-workspace.yaml`, with a pointer to the ADR.
- **pnpm 11+ release-age cooldown** defaults to 1440 minutes, but in non-strict mode. On the
  first install pnpm silently added exclusions for packages published that morning
  (`vite@8.3.6`, `jsdom@31.0.0`, `eslint-plugin-boundaries@7.4.2`). We set the value explicitly
  (strict mode) and pinned the previous versions instead.
- **bulletproof-react now discourages barrel files** (they can hurt Vite tree-shaking and dev
  performance) and imports feature files directly. We keep exactly one small `index.ts` per feature
  as an enforced public API (five named exports, not a re-export of everything). The trade-off is
  recorded in [ADR 0003](adr/0003-project-structure.md).
- **React 19 + Testing Library:** when a component suspends on `use(promise)`, `findBy*`
  polling alone did not flush the resolution in jsdom. Rendering inside `await act(...)` does.
  This is documented in the integration test helper.
- **React Compiler in tests:** compiled components carry memo-cache branches that a single
  render never takes, which skews branch coverage. The compiler is disabled under Vitest; the
  e2e suite runs the compiled production build ([ADR 0008](adr/0008-testing-strategy.md)).

## Deliberately not adopted

Each item, with the trigger that would bring it in, is in
[ADR 0013](adr/0013-deliberately-excluded.md): React Server Components / a framework,
TanStack Query, a global store, a router, MSW, i18n, a component library, Storybook,
a PWA/service worker, error monitoring, Docker, a monorepo, TS 7 native typecheck.
