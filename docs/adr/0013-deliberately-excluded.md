# 0013. What we deliberately did not add

- Status: Accepted
- Date: 2026-11-05

## Context

YAGNI: every dependency and layer must earn its place in _this_ app. Leaving something out is
also a decision, so it is recorded here together with the signal that would change it.

## Decision

| Not added                                                                                      | Why not now                                                                                                                                                                   | Add it when                                                                                                                    |
| ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Framework (Next.js, React Router framework mode, TanStack Start) / **React Server Components** | No server: data is in the browser. RSC needs a server or build-time rendering and gives a localStorage SPA nothing (no data to fetch on the server, no secrets, tiny bundle). | SEO/first-paint matters, data lives behind an API you want to call server-side, or there are several routes with data loading. |
| **TanStack Query**                                                                             | One local data source, read once. See [ADR 0005](0005-state-management.md).                                                                                                   | A real network API plus caching, refetch, retry, pagination or shared server data across screens.                              |
| **Zustand / Jotai / Redux**                                                                    | Each piece of state has a single owner close to where it is used.                                                                                                             | Client state that many distant components read and write (e.g. editor state, multi-step wizards).                              |
| **Router**                                                                                     | One page, one query param. See [ADR 0007](0007-url-state-without-router.md).                                                                                                  | A second page.                                                                                                                 |
| **MSW**                                                                                        | No HTTP layer. See [ADR 0011](0011-persistence.md).                                                                                                                           | An HTTP repository exists and needs tests.                                                                                     |
| **i18n** (react-intl, i18next, Lingui)                                                         | English-only. Strings are few and live in the components.                                                                                                                     | A second locale is required. Extract strings then.                                                                             |
| **Component library / design system / Storybook**                                              | Five controls, one screen.                                                                                                                                                    | Shared components across features or teams, or designers need a catalogue.                                                     |
| **`react-error-boundary`**                                                                     | The ~30-line `shared/ui/ErrorBoundary` covers the one use (remount by `key` to retry).                                                                                        | Several boundaries need reset keys, `onError` reporting or hook-based APIs.                                                    |
| **Error monitoring** (Sentry, …)                                                               | No production deployment. React logs caught errors to the console.                                                                                                            | The app is deployed: wire it into `createRoot`'s `onCaughtError`/`onUncaughtError`.                                            |
| **PWA / service worker, cross-tab sync**                                                       | Not in the requirements.                                                                                                                                                      | Offline install or multi-tab use becomes a requirement (`storage` event for sync).                                             |
| **Undo / confirmation for delete**                                                             | The spec forbids native `confirm`. A custom dialog for a reversible todo is friction. Rollback covers failures.                                                               | Data becomes costly to lose: add an "Undo" toast rather than a confirm dialog.                                                 |
| **Docker / deployment config**                                                                 | `pnpm build` produces static files that any static host can serve.                                                                                                            | There is a deployment target.                                                                                                  |
| **Monorepo tooling** (Turborepo, Nx)                                                           | One package.                                                                                                                                                                  | A second package (e.g. a shared UI kit or an API).                                                                             |
| **TypeScript 7 native (`tsgo`) typecheck**                                                     | typescript-eslint needs TS ≤6.0. See [ADR 0002](0002-stack-and-toolchain.md).                                                                                                 | typescript-eslint supports TS 7.                                                                                               |
| **Vitest Browser Mode, cross-browser e2e**                                                     | jsdom + Chromium e2e cover the risk at this size.                                                                                                                             | Layout- or browser-specific bugs appear.                                                                                       |
| **Visual regression testing**                                                                  | No design system to protect.                                                                                                                                                  | A component library exists.                                                                                                    |
